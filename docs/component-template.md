# Component README Template

Copy this structure into `<component>/README.md`. Delete sections that genuinely don't apply — but say why when the omission matters.

```markdown
# <component-name>

One-paragraph purpose. Who reuses this, what pain it removes.

## Non-goals

What this explicitly does NOT do.

## Features

- ...
- ...

## Runtime & dependencies

- Language / runtime + version
- Dependencies (with why each one earned its place)

## Setup

Minimal steps from a clean checkout.

## Configuration

| Key | Required | Default | Description |
| --- | -------- | ------- | ----------- |
|     |          |         |             |

## Usage

Minimal, runnable example.

## Security considerations

Threat model, trust boundaries, secret handling, input validation.

## Reliability & failure behavior

Timeouts, retries (policy + jitter), idempotency, cleanup, shutdown.

## Observability

Logs, correlation IDs, metrics, health checks.

## Tests & verification

How to run tests. Commands actually executed + results.

## Limitations & readiness status

What is NOT tested, known limits, deployment notes.
Honest verdict: experimental / preview / production-ready for <specific scope>.
```
